FaithPath – kompletter Neubau
================================
Diese App wurde neu aufgebaut. Wiederverwendet wurden ausschließlich Inhalts-/Medienressourcen:
- Lutherbibel 1912: 66 Bücher, 31.102 Verse, einzelne Verse
- 7 Olivenbaum-Stufen
- 20 vorhandene, geprüfte Bibelgeschichten mit Quiz + Reflexionsfragen

Kernfluss:
Bibel → Markieren/Notiz → Mit Weg verbinden → Handeln → Rückblick → selbst bestätigte Entwicklung → Baum.

Keine Faith Points, keine Streaks, keine Glaubensbewertung, keine Grok-Verbindung.
Daten werden lokal im Browser gespeichert; Backup/Import ist integriert.


UI REFRESH: Premium visual pass with calm tree-stage motion, glassy navigation, refined spacing/cards, tactile transitions, reduced-motion support. Based on ReaderFix stable Bible reader.
