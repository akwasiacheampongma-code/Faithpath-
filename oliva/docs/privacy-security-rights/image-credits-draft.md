# Bildnachweise · Entwurf, rechtlich zu prüfen

Die Dateiliste der privaten Vorschau belegt 64 Webgrafiken. Acht Motive zeigen Landschaften oder Bibelszenen. Davon sind sechs konkreten Geschichten zugeordnet. Der Nutzungsrahmen für eine öffentliche Verwendung muss mit den tatsächlichen Rechteinhabern, Vertragsbedingungen und Märkten abgeglichen werden.
